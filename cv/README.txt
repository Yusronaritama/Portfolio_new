Petunjuk Penyimpanan File CV / Resume Lokal
==============================================
Folder ini disiapkan untuk menyimpan file CV / Resume Anda.

Nama file default yang dipanggil pada tombol portofolio:
cv/CV_Yusron_Aritama.pdf

Format yang didukung:
- Dokumen PDF (.pdf) - Sangat direkomendasikan karena browser dapat langsung menampilkannya secara interaktif.
- Gambar (.png, .jpg, .webp) jika CV Anda berbentuk gambar.

Cara Menggunakan:
1. Simpan file CV Anda ke dalam folder ini dengan nama:
   CV_Yusron_Aritama.pdf
2. Jika Anda menggunakan nama file berbeda (misal: cv.pdf atau Resume_Yusron.pdf),
   Anda cukup menyesuaikan atribut href="..." pada tombol CV di file index.html.
