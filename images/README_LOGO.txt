Petunjuk Logo Pribadi / Brand Navbar
=======================================
Folder ini digunakan untuk menyimpan berkas logo Anda yang tampil di bagian Navbar (kiri atas) dan Footer website.

Lokasi Berkas Default:
images/logo/logo.png

Cara Mengganti Logo:
1. Siapkan logo Anda (disarankan gambar berorientasi kotak/square 1:1 dengan format PNG transparan atau JPG beresolusi tajam, misalnya 200x200 atau 500x500 piksel).
2. Simpan logo tersebut ke dalam folder images/logo/ dengan nama:
   logo.png
   (atau logo.jpg / logo.svg)
3. Jika nama berkas berbeda, Anda cukup mengganti atribut src="..." pada tag <img> id="nav-brand-logo" di file index.html:
   <img id="nav-brand-logo" src="images/logo/nama-logo-anda.png" ... />
