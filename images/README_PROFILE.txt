Petunjuk Foto Profil Lokal
==========================
Folder ini digunakan untuk menyimpan foto profil Anda yang akan ditampilkan di halaman utama website dalam bingkai bundar (circular frame).

Cara Menambahkan Foto:
1. Siapkan foto profil Anda (disarankan berorientasi kotak/square 1:1, contoh: 500x500 piksel).
2. Simpan foto tersebut ke dalam folder ini dengan nama:
   profile.jpg
   (atau profile.png / profile.webp)
3. Website akan otomatis mendeteksi dan menampilkan foto Anda di Hero Section.
4. Jika nama berkas berbeda, Anda cukup mengganti atribut src="..." pada tag <img> id="user-profile-img" di file index.html.
