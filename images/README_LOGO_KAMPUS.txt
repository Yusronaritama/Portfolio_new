Petunjuk Logo Kampus / Universitas
===================================
Folder ini digunakan untuk menyimpan berkas logo universitas tempat Anda kuliah.

Nama berkas yang dipanggil di kode:
images/logo_kampus.png (atau images/logo_ubp.png)

Format yang didukung:
- Format PNG transparan (.png) sangat disarankan agar menyatu rapi dengan latar belakang kartu.
- Format JPG (.jpg) atau WebP (.webp) juga didukung.

Jika Anda menggunakan nama berkas berbeda, cukup sesuaikan atribut src="..." pada elemen <img> dengan id="campus-logo-img" di file index.html.
